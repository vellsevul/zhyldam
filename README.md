# Zhyldam ⚡

**Жылдам** — «быстрый» по-казахски. Черновик приложения мото-такси для Алматы: мопеды, мотоциклы и спортбайки для тех, кто торопится или любит скорость.

## 👉 [Открыть приложение: vellsevul.github.io/zhyldam](https://vellsevul.github.io/zhyldam/)

Лучше открывать с телефона и разрешить доступ к геопозиции.

Другие адреса:
- https://zhyldam.vercel.app — тот же сайт на Vercel (у некоторых провайдеров не открывается)
- https://claude.ai/artifact/QCBoNC88W9YtV85PdQyxkU — приватная версия на claude.ai с живой связью пассажир ↔ райдер

## Что умеет

**Вход:** регистрация и вход по телефону или email с паролем (хранится хэш). Кнопки Google и Apple пока имитируют вход.

**Пассажир**
- Точная геопозиция по GPS телефона (с точностью в метрах). Точку посадки и назначения можно поставить пином на карте
- Поиск адресов, маршрут по реальным дорогам, время на мото и на авто
- Балл пробок 1–10 (кнопка 🚦)
- Режимы заказа: ⚡ **Быстро** (фиксированная цена) и 🤝 **Торг** (как в inDrive: предлагаешь цену, райдеры отвечают)
- Транспорт: 🛵 Мопед, 🏍️ Мото, 🏁 Turbo (спортбайк)
- Райдера видно на карте: откуда едет, где он сейчас, через сколько минут приедет
- Свою геопозицию райдеру пассажир показывает только по своему разрешению
- Звонок (подменный номер), чат с райдером, ссылка на поездку для близких, экран безопасности
- Оплата: наличные, Kaspi перевод, привязка карты (номер проверяется, сохраняются только последние 4 цифры)
- История поездок с датой и временем, чек с разбивкой стоимости

**Райдер** (меню → «Стать райдером» или ссылка с `#driver`)
- Профиль байка, обязательное подтверждение запасного шлема для пассажира
- Заказы рядом, принять или поторговаться, этапы поездки по GPS
- Заработок за день, история и чеки

**Ещё:** служба поддержки (чат), настройки: тема светлая/тёмная/системная, фото профиля, имя, телефон.

## Где что работает

| | GitHub Pages / Vercel | claude.ai |

| Настоящая карта OpenStreetMap | ✅ | ❌ нарисованная карта |
| Точный GPS | ✅ | ❌ точку ставишь вручную |
| Маршруты по дорогам и поиск адресов | ✅ | ❌ по нарисованным улицам |
| Пассажир и райдер видят друг друга с разных устройств | ❌ симуляция | ✅ |
| Поддержка отвечает с помощью Claude | ❌ готовые ответы | ✅ |

Живую связь на своём хостинге даёт `server.js`, его можно бесплатно запустить на Render (см. ниже).

Ограничения черновика:
- Маршруты (OSRM), адреса (Nominatim) и тайлы OpenStreetMap — бесплатные публичные сервисы с лимитами. Для настоящего запуска нужны свои ключи, например 2GIS API или Mapbox.
- Пробки — модель по часу пик, а не реальные данные.
- Аккаунты, карты и история хранятся в браузере. Деньги не списываются, звонки не совершаются.

## Живая связь на Render (бесплатно)

1. render.com → New → Blueprint → выбери репозиторий `zhyldam` (настройки уже в `render.yaml`).
2. Получишь адрес вида `https://zhyldam.onrender.com`: там сайт и живая связь работают вместе.
3. Чтобы живая связь работала и на GitHub Pages, добавь перед `live.js` в `index.html`:
   ```html
   <script>window.ZHYLDAM_SERVER = 'https://zhyldam.onrender.com'</script>
   ```

На бесплатном тарифе сервер засыпает после 15 минут без посетителей, первое открытие потом занимает около минуты. Текущие поездки хранятся в памяти и сбрасываются при перезапуске.

## Запуск на своём компьютере

```bash
npm start
```

Открой http://localhost:3000 в двух вкладках: в одной пассажир, в другой `#driver`.

## Файлы

- `index.html`, `style.css` — разметка и стили
- `map.js` — карта, маршруты, пробки, GPS, адреса
- `live.js` — живая связь (claude.ai или свой сервер)
- `account.js` — вход, настройки, оплата, история и чеки, поддержка, безопасность, чат, ссылка на поездку
- `app.js` — пассажир, `driver.js` — райдер
- `server.js`, `package.json`, `render.yaml`, `railway.json` — сервер живой связи
- `logo.svg`, `vendor/leaflet/` — логотип и библиотека карты
