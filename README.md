# Zhyldam ⚡

**Жылдам** — «быстрый» по-казахски. Черновик приложения мото-такси для Алматы: мопеды, мотоциклы, спортбайки.

## Что умеет
**Вход:** регистрация и вход по телефону или email с паролем (хранится хэш), кнопки Google и Apple пока имитируют вход.

**Пассажир**
- Геопозиция определяется автоматически (где браузер разрешает), точку посадки и назначения можно поставить пином на карте
- Маршрут строится по улицам с учётом пробок, мото объезжает пробки лучше, чем авто
- Балл пробок 1–10 (кнопка 🚦), цветные пробки на улицах
- Режимы ⚡ Быстро и 🤝 Торг (как в inDrive)
- Райдера видно на карте всегда: откуда едет, где он сейчас, через сколько минут приедет
- Свою геопозицию райдеру пассажир показывает только по своему разрешению
- Звонок (подменный номер), чат с райдером, ссылка на поездку для близких, кнопка безопасности
- Оплата: наличные, Kaspi перевод, привязка карты (проверка номера по Luhn, сохраняются только последние 4 цифры)
- История поездок с датой и временем, чек с разбивкой стоимости

**Райдер** (меню → «Стать райдером» или ссылка с `#driver`)
- Профиль, обязательное подтверждение запасного шлема для пассажира
- Заказы рядом, торг, этапы поездки, заработок за день, история и чеки

**Ещё:** служба поддержки (чат), настройки (тема светлая/тёмная/системная, фото профиля, имя, телефон).

## Живая связь
В опубликованной версии на claude.ai пассажир и райдер видят друг друга в реальном времени:
открой ссылку в двух вкладках или на двух устройствах под одним аккаунтом, в одной пассажир, в другой `#driver`.
Без этой связи (например, при открытии файла локально) райдеры и пассажиры симулируются.

## Запуск локально
```bash
python3 -m http.server 8000
```
Открой http://localhost:8000

## Хостинг
Это статический сайт без сборки: подходит Vercel, Netlify или GitHub Pages (импортируй репозиторий, настройки не нужны).
Живая связь и ответы поддержки от Claude работают только в версии на claude.ai. Для хостинга вне claude.ai нужен свой сервер реального времени (например, на Railway).

- `app.js` — пассажир, `driver.js` — райдер
