# Zhyldam ⚡

**Жылдам** — «быстрый» по-казахски. Черновик приложения для вызова мото-такси (мопеды и мотоциклы) для тех, кто торопится или любит скорость.

## Что есть
**Пассажир**
- Интерфейс в стиле Uber: карта на весь экран + нижняя шторка
- Транспорт: 🛵 Мопед · 🏍️ Мото · 🏁 Turbo (спортбайк)
- Режимы: **⚡ Быстро** (фикс. цена, райдер едет сразу) и **🤝 Торг** (как в inDrive: своя цена → предложения райдеров → выбираешь или поднимаешь цену)
- Райдер едет по карте, поездка, оценка и чаевые

**Райдер** (меню ☰ → «Стать райдером», или ссылка с `#driver`)
- Профиль: имя, байк, класс, госномер
- Статус «На линии», заказы рядом с ценой на карте
- Быстрые заказы — принять сразу; торг — принять или предложить свою цену (+100/+200/+300)
- Поездка по этапам: к пассажиру → «Я на месте» → «Начать поездку» → «Завершить», заработок за день

Всё работает в браузере, без сервера: пассажиры и райдеры симулируются. Карта Алматы нарисована векторами (`map.js`), интернет для неё не нужен.

## Файлы
- `index.html` — разметка, `style.css` — стили
- `map.js` — карта и общие утилиты, `app.js` — пассажир, `driver.js` — райдер
- `logo.svg` — логотип, `vendor/leaflet/` — библиотека карты
