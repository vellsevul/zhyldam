# Zhyldam ⚡

**Жылдам** — «быстрый» по-казахски. Черновик приложения мото-такси для Алматы: мопеды, мотоциклы, спортбайки.

**Открыть:** https://claude.ai/artifact/QCBoNC88W9YtV85PdQyxkU (приватная страница на claude.ai)

## Что умеет
**Вход:** регистрация и вход по телефону или email с паролем (хранится хэш), кнопки Google и Apple пока имитируют вход.

**Пассажир**
- Геопозиция определяется автоматически (где браузер разрешает), точку посадки и назначения можно поставить пином на карте
- Маршрут строится по улицам с учётом пробок, мото объезжает пробки лучше, чем авто
- Балл пробок 1–10 (кнопка 🚦), цветные пробки на улицах
- Режимы ⚡ Быстро и 🤝 Торг (как в inDrive)
- Райдера видно на карте всегда: откуда едет, где он сейчас, через сколько минут приедет
- Свою геопозицию райдеру пассажир показывает только по своему разрешению
- Звонок (подменный номер), чат с райдером, ссылка на поездку для близких, кнопка безопасности
- Оплата: наличные, Kaspi перевод, привязка карты (проверка номера по Luhn, сохраняются только последние 4 цифры)
- История поездок с датой и временем, чек с разбивкой стоимости

**Райдер** (меню → «Стать райдером» или ссылка с `#driver`)
- Профиль, обязательное подтверждение запасного шлема для пассажира
- Заказы рядом, торг, этапы поездки, заработок за день, история и чеки

**Ещё:** служба поддержки (чат), настройки (тема светлая/тёмная/системная, фото профиля, имя, телефон).

## Живая связь
Пассажир и райдер видят друг друга в реальном времени: на claude.ai через встроенную связь, на Railway через `server.js`.
Если ни того ни другого нет (файл открыт напрямую), райдеры и пассажиры симулируются.

## Запуск локально
```bash
npm start
```
Открой http://localhost:3000 в двух вкладках: в одной пассажир, в другой `#driver`.

## Хостинг на Railway
1. Зайди на railway.com через GitHub.
2. New Project → Deploy from GitHub repo → выбери `zhyldam` и нужную ветку.
3. Railway сам запустит `npm start` (настройки в `railway.json`, зависимостей нет).
4. Settings → Networking → Generate Domain: получишь адрес вида `zhyldam-production.up.railway.app`.

Сервер раздаёт сайт и передаёт живые данные между пассажирами и райдерами (Server-Sent Events: `/rt/stream`, `/rt/presence`).
Если сайт лежит отдельно (например, на Vercel), а сервер на Railway, добавь перед `live.js` в `index.html`:
```html
<script>window.ZHYLDAM_SERVER = 'https://zhyldam-production.up.railway.app'</script>
```
Состояние живёт в памяти сервера: после перезапуска текущие поездки сбрасываются.

## Файлы
- `index.html`, `style.css`
- `map.js` — карта, граф улиц, маршруты и пробки
- `live.js` — живая связь (claude.ai или свой сервер)
- `account.js` — вход, настройки, оплата, история и чеки, поддержка, безопасность, чат, ссылка на поездку
- `app.js` — пассажир, `driver.js` — райдер
- `server.js`, `package.json`, `railway.json` — сервер для Railway
- `logo.svg`, `vendor/leaflet/`
