# Zhyldam ⚡

**Жылдам** — «быстрый» по-казахски. Прототип приложения для вызова мото-такси (мопеды и мотоциклы) для тех, кто торопится или любит скорость.

## Что есть
- Интерфейс в стиле Uber: карта на весь экран + нижняя шторка
- Выбор транспорта: 🛵 Мопед · 🏍️ Мото · 🏁 Turbo (спортбайк)
- Два режима заказа:
  - **⚡ Быстро** — фиксированная цена, ближайший райдер едет сразу
  - **🤝 Торг** (как в inDrive) — предлагаешь свою цену, райдеры присылают предложения/контр-предложения, выбираешь лучшее или поднимаешь цену
- Анимация райдера на карте, поездка, оценка и чаевые
- Оплата: наличные / Kaspi / карта, опция «нужен шлем»

## Запуск
Просто открой `index.html` в браузере (лучше в режиме мобильного экрана), или:
```bash
python3 -m http.server 8000
```
и зайди на http://localhost:8000

Это демо: райдеры и предложения симулируются в браузере, бэкенда пока нет.
